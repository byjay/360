## 마스터 스크린샷 해석 (AutoCAD MLEADER 스타일)
- 번호 원(풍선) ①②③④가 **세로 일렬, 같은 간격**으로 오른쪽에 정렬되어 있다.
- 각 풍선에서 **짧은 수평선(랜딩) → 꺾여서 사선 리더선 → 끝에 빨간 화살촉**이 대상 위치를 가리킨다.
- 리더선과 화살촉은 빨간색, 풍선은 흰 원 테두리에 흰 번호(어두운 CAD 배경). 우리 도면은 흰 배경이므로 **배경에 맞춰 대비를 확보**한다.

## 판정 기준 (지휘자 확정)
1. **데이터**: 기존 `pin.x, pin.y`(페이지 %) = **화살촉 끝(대상 위치)**은 그대로 둔다. 풍선 위치는 `pin.callout = {x, y}`(페이지 %, 절대좌표)로 **추가**한다. 없으면 기본값 = 대상에서 오른쪽 위로 일정 거리(화면 px 기준을 %로 환산). 레거시 핀은 callout 없이도 정상 표시된다(유실 0). 저장·병합은 기존 경로(`_markDirty` → `stampChanged` LWW, `_mergePins`)를 그대로 탄다.
2. **표시 대상**: **CHECKER 핀은 기본 리더선 표시**(번호만 매기는 CAD 점검 용도). 360 핀은 현행 물방울을 유지하되, 설정에서 "360도 리더선으로 표시"를 켤 수 있게 한다(모드별 토글 1개, 기본 OFF). 풍선 번호는 `PinSeries.formatNo` SoT를 쓴다(CHECKER 1,2 / 360 P1).
3. **렌더**: 도면 변환 레이어(`#map-transform`) 안에 SVG 오버레이를 둔다. 확대·축소·팬과 같이 움직이되, **선 두께·풍선 크기·글자는 화면 기준 일정**하게 유지한다(줌 역보정). 구성: 화살촉(빨강, 채움 삼각형) → 사선 리더 → 풍선 쪽 짧은 수평 랜딩(풍선 방향으로) → 원형 풍선(번호). 풍선이 대상의 왼쪽에 있으면 랜딩도 반대 방향으로 그린다. 선택(focused)·hover 강조와 기존 클릭 동작(핀 패널 열기)은 **풍선 클릭**에 연결한다.
4. **편집**: 풍선 드래그 = callout만 이동(대상 고정). 기존 "위치 이동" = 대상(화살촉) 이동. 모바일 터치 드래그도 지원한다.
5. **정렬 기능 — 🔴 마스터 2차 지시: "리더선으로 적용 시 정렬 위치를 클릭하면 일정한 간격으로 정렬되게"**
   - 흐름: 풍선 선택(기존 일괄 선택 UI 재사용. 선택이 없으면 현재 구역·영역의 해당 모드 핀 전체) → [정렬 ↕세로 / ↔가로] 선택 → 안내 "도면에서 정렬할 위치를 클릭하세요" → **사용자가 도면을 클릭한 지점이 정렬 기준**이 된다.
   - **세로**: 모든 풍선의 x = 클릭 x. 첫 풍선의 y = 클릭 y. 이어서 아래로 **번호 순, 등간격** 배치. 간격은 화면 기준 일정(풍선 지름 × 1.6, 이름 있는 상수)이고 현재 줌을 역보정해 페이지 %로 저장한다.
   - **가로**: 모든 풍선의 y = 클릭 y. 첫 풍선의 x = 클릭 x. 이어서 오른쪽으로 번호 순, 등간격.
   - 클릭 전 Esc나 [취소]를 누르면 정렬하지 않는다. 화살촉(대상)은 절대 움직이지 않고 callout만 바꾼다.
   - 정렬 미리보기: 클릭 전 마우스 이동(모바일은 탭 후 확인 버튼)으로 정렬 결과 점선 미리보기를 보여 주면 좋다(필수 아님 — 단순성 우선).
   - 정렬 직후 토스트에 [되돌리기] 1회를 둔다(정렬 전 callout 스냅샷).
6. **미니맵·뷰어 배포·PDF 내보내기**: 미니맵(07_Radar)은 점만 그리고 리더선은 생략해도 된다. 뷰어 배포 화면은 편집 화면과 같은 리더 표시를 하되 편집(드래그·정렬)은 비활성. PDF/이미지 내보내기 기능이 있으면 리더도 포함하고, 없으면 보고만 한다.
7. 대비: 흰 도면 위 빨간 리더(≥3:1), 풍선 번호 ≥4.5:1. CSS 3개 파일을 전수 확인한다.
