## 판정 기준 (지휘자 확정)
1. **대역 정의**: 100 단위. 대역 k = `(k-1)*100+1 … k*100` → 1~100, 101~200, 201~300 …. 마스터 원문 "0~100"은 번호가 1부터 시작하므로 1~100으로 해석한다(0번 핀 없음). 대역 크기 100은 이름 있는 상수다. CHECKER는 `1…100`, 360은 `P1…P100`으로 **모드별로 독립**이다.
2. **다음 번호** = 내가 고른 대역 안에서 **모든 사용자의 같은 계열 핀** 중 최댓값 + 1이다. 대역에 핀이 없으면 대역 시작값이다. 대역 끝(예: 100)에 닿으면 "대역이 가득 찼습니다 — 다음 대역(101~200)으로 바꿀까요?" 확인을 띄운다. 다른 대역으로 넘쳐 들어가지 않는다.
3. **동시 생성 충돌**(603f9b9의 `resolveConcurrentNos` 수정): 같은 대역을 쓰는 두 사람이 같은 번호를 만들면, 나중에 만든 쪽을 **같은 대역 안의 다음 빈 번호**로 옮긴다. 대역 밖으로는 절대 옮기지 않는다. 대역이 가득 찼으면 옮기지 않고 중복 표시만 한다. 수동 번호(`labelManual`) 보호는 유지한다.
4. **메뉴(직관적 UI)**: 상단 `시작 #` 칸을 **[번호 대역 ▾]** 버튼으로 바꾼다. 누르면 시트/드롭다운이 열린다.
   - 현재 모드 표시(CHECKER / 360)
   - 대역 칩 목록: `1–100`, `101–200`, `201–300`, … (사용 중인 대역 + 다음 빈 대역 1개까지 표시). 각 칩에 **사용자(작성자 이름/이니셜)와 사용 개수**를 표시한다. 예: `101–200 · 김OO 12개`. 내 대역은 강조한다.
   - **다음 번호 미리보기**: "다음 핀 = 113" (360이면 "P113")
   - [직접 입력] 접힘 영역: 임의 시작번호(고급). 입력값이 속한 대역으로 자동 귀속된다.
   - 선택은 **사용자·프로젝트·모드별로 기억**한다(서버에 저장할지 localStorage로 둘지 결정하고 근거를 보고하라. 다른 기기에서도 같은 대역을 쓰려면 서버가 낫다. 마이그레이션이 필요하면 파일만 만든다).
   - 상단바에는 현재 대역을 짧게 표시한다: `대역 101–200 · 다음 113`. 모바일에서도 같은 시트를 쓴다.
5. 24_Settings의 기존 시작번호 설정은 이 메뉴로 일원화한다(SoT 1개, 중복 UI 제거).
6. 대비 ≥4.5:1, 375px에서 넘침 없음. CSS 3개 파일을 전수 확인한다.

## 🔴 마스터 확정 (2026-10-01, Jev "지시 모호 0.75 → 되물어라" 후)
- **배정**: 멤버별 **자동 배정 + 본인 변경 가능**. 프로젝트 소유자 = 1~100, 이후 멤버가 된 순서(멤버 추가 시각)대로 101~200, 201~300 …의 **빈 대역**을 자동 배정한다. 메뉴에서 본인이 다른 **빈** 대역으로 바꿀 수 있다(남이 쓰는 대역 선택은 확인창 후 허용, 같은 대역 안에서 이어 씀). CHECKER와 360은 같은 대역 번호를 쓴다(예: 101~200 → CHECKER 101… / 360 P101…). 단, 각 계열의 번호는 독립적으로 증가한다.
- **저장**: **서버**(프로젝트 멤버 정보). `project_members`(또는 실제 멤버 테이블명 확인)에 `num_band INTEGER`(대역 번호 k) 컬럼을 추가한다 → 마이그레이션 파일 `0032_member_num_band.sql`(번호 확인)을 만들고 prod 적용은 지휘자가 한다. 소유자는 멤버 테이블에 없으면 band 1로 간주한다. 멤버 추가 API(`POST /api/projects/:id/members`, 초대 수락 accept, 가입 자동 편입 `claimPendingInvites` — 3fa120f)에서 빈 대역을 자동 배정한다(공유 헬퍼 1개). `PUT /api/projects/:id/members/me/band`로 본인 변경(권한: 본인만, 소유자·super는 누구든). 기존 멤버(컬럼 NULL)는 조회 시 멤버 추가 순서로 계산해 채운다(지연 백필, 결정론).
- 메뉴 칩의 "사용자·개수"는 서버 대역 배정 + 실제 핀 번호를 함께 표시한다.
