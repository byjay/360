## 판정 기준
1. **뷰어 도움말**: 뷰어 배포 화면에도 [?] 버튼과 도움말을 둔다. 내용은 **열람자용**이다: 도면 이동·확대(마우스/손가락), 핀 종류(CHECKER 주황 배지·리더선 / 360 블루 물방울), 360 뷰어 조작(드래그·두 손가락 줌·미니맵·꼭지점 보기·전체화면·닫기), 트리(구역→영역→CHECKER/360), 앱 설치. 편집 전용 기능(핀 생성·삭제·정렬·합치기)은 숨긴다. 기존 Help 모듈을 재사용하고 역할별 섹션만 분기한다(SoT 1개).
2. **개발자 문의 노트**: 도움말 하단(편집 화면과 뷰어 둘 다)에 [개발자에게 문의] → 작은 폼(제목·내용·회신 이메일(선택)·현재 화면 정보 자동 첨부: 프로젝트명/배포본 id/모드/브라우저/앱 버전 해시) → [보내기].
   - 서버: `POST /api/inquiries` → **D1에 저장**(신규 테이블 `inquiries`, 마이그레이션 파일 생성, prod 적용은 지휘자) + **Resend로 `designsir@seastargo.com`에 메일 발송**(기존 Resend 발송 경로·발신 `scan360@secms.tech` 재사용. 키는 Cloudflare 시크릿에서만 읽는다).
   - 남용 방지: IP/세션당 분당 3건 제한, 본문 길이 상한, HTML 이스케이프. 로그인 없는 열람자도 보낼 수 있다(공유 뷰어 사용자).
   - 메일 발송이 실패해도 D1 저장이 됐으면 사용자에게는 "접수됨"으로 알리고 서버 로그에 실패를 남긴다. 저장까지 실패하면 실패를 알린다(조용한 실패 금지).
   - 관리자(super)는 기존 관리자 패널(Designers/로그)에서 문의 목록을 볼 수 있게 한다(간단 목록 + 처리 완료 체크).
3. 대비 ≥4.5:1, 모바일 375px에서 폼이 화면을 넘치지 않는다.
