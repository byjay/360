# 마스터 요청 기능 전수 체크리스트 (2026-09-29 기준, 세션 원문에서 추출)
판정: ✅ 라이브 동작 확인 / 🟡 코드만 있음(라이브 미확인 또는 부분) / ❌ 없음·깨짐. 근거 = 파일:라인 + 라이브 측정.

## A. 모드·번호
A1 모드는 CHECKER / 360 두 개만(보기 모드 없음), 상단 세그먼트로 전환
A2 CHECKER 번호 1,2,3 / 360 번호 P1,P2 — 계열별 채번
A3 시작번호를 각 모드에서 설정(상단 인라인 + 설정 화면)
A4 필터는 [CHECKER][360] 두 칩만(밸브/설비 등 아이콘 필터 없음)
A5 CHECKER: 빈 곳 클릭 = 번호 핀만 생성, 다른 반응 없음
A6 360: 핀 생성 즉시 사진 등록 창
A7 기존 핀 클릭 = 패널(번호 수정·등록 가능)
A8 번호 리셋(일괄 재번호) 동작
A9 마커에 번호 항상 표시

## B. 구역·영역·트리
B1 트리 최상단 = 프로젝트 이름 → 구역 → 영역 → 핀 목록(정렬)
B2 프로젝트 노드 클릭 = 원래 전체 도면(구역·영역을 만들어도 원본이 사라지지 않음)
B3 구역 = 지정 부분만 새 페이지로 크게(벡터 복사 / 크롭 맞춤, 팬 제한)
B4 영역 = 구역 하위, 이름이 트리에 표시
B5 허브 카드 아래 구역→영역 리스트(기본 펼침)
B6 트리 제목이 정확히 표시(#1 중복 없음)
B7 핀 삭제 동작(PWA에서도, Prompt.confirm)
B8 🆕 관리자 핀 일괄삭제

## C. 화질
C1 도면 저장 시 원본을 고해상도로 보관(무손실, 2000px 상한 없음)
C2 확대해도 벡터로 재렌더되어 깨지지 않음(DPR 기준)
C3 구역 잘라오기도 최고 해상도 유지

## D. 360 사진·휴대폰
D1 휴대폰에서 360 사진 등록
D2 핀 생성 시각(createdAt) 기록
D3 촬영 시각이 가장 가까운 360 사진 자동 연결(THETA X 파일명 R0013783_YYYYMMDDhhmmss.JPG 파싱, 최신 파일부터)
D4 자동 등록 경로 = /내장 저장공간/Pictures/RICOH THETA 안내 또는 지정
D5 오프라인 작업 후 복귀 시 동기화(연결하기 배너)
D6 THETA 와이파이 연결 감지 시 연동
D7 저장명 = 영역이름_시간, 사진 정보를 바로 알아볼 수 있게(캡션·뷰어 제목)
D8 휴대폰 접속 시 바로 앱 설치(첫 화면 설치, 7일 스누즈)

## E. UI 정리
E1 핀 패널 상·하단 중복 제거, 정렬
E2 상단바 ●⊞ 정체 제거·액션 정확
E3 모바일: 핀 등록·사진 등록이 메인, 나머지는 서브메뉴, 아이콘 크기 축소
E4 360 뷰어 기능 전부 정확 동작(버튼 21개), 모바일에서 닫기 가능
E5 검은 영역 때문에 글자가 안 보이는 곳 없음(대비 ≥4.5:1)
E6 360 탭 안내문이 사진 위에 겹치지 않음, 긴 사진이 패널을 늘리지 않음

## F. 협업·권한
F1 1명이 프로젝트 생성 → 초대 → 초대받은 사람이 같은 프로젝트에서 작업
F2 3명 동시 작업 시 충돌 없음(409·병합)
F3 오프라인 작업 후 서버 업데이트
F4 다른 사람의 포인트를 구역 단위로 합치기
F5 삭제된 핀이 다시 살아나지 않음(tombstone)
F6 공유 코드 회사 게이트(Jev)

## G. 배포
G1 배포 즉시 반영(캐시버스팅, 캐시 유지 상태에서도 새 코드)
