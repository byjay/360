OpenAI 호환 엔드포인트(Groq 등)를 설정합니다. API 키는 보안상 Cloudflare Secret으로만 저장됩니다(여기서 직접 저장하지 않음).

상태 확인 중…
API 키 변경 방법(키는 코드/DB에 저장 안 함): npx wrangler pages secret put AI_API_KEY 배포 환경에서 위 명령으로 키를 넣으면 즉시 활성화됩니다. Base URL·모델은 아래 저장 버튼으로 저장됩니다.

Firebase 연결

본인 Google 계정의 Firebase 프로젝트에 바로 연결합니다. 코드 수정 없이 아래에 값을 넣고 저장하면 즉시 활성화됩니다.

상태 확인 중…
3분 안내 — Firebase Console에서 값 얻기
  1. console.firebase.google.com 접속 → 본인 Google ID 로그인
  2. "프로젝트 추가" → 이름 입력(예: seastar-viewer)
  3. 좌측 톱니바퀴 → 프로젝트 설정 → "내 앱" → 웹앱(</>) 추가
  4. 표시되는 firebaseConfig = { ... } 전체를 복사 → 아래에 붙여넣기
  5. Authentication → 시작하기 → Google 공급업체 사용 설정
  6. Firestore Database → 데이터베이스 만들기
